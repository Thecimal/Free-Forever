# Getting Support for Free-Forever

Welcome! Here is how you can find help, ask questions, or report problems when working with **Free-Forever**.

---

## Where to Look First

1. **[README.md](README.md):** Architectural diagrams, capabilities, supported configuration parameters, and CLI commands.
2. **[Configuration Guide (.env.example)](.env.example):** Example environment variables for OmniRoute, local Ollama models, and execution strategies.
3. **[GitHub Issues](https://github.com/Thecimal/Free-Forever/issues):** Search existing and closed issues to see if your question or issue has already been solved.

---

## How to Get Help

### 1. General Questions & Discussions
For questions on architecture, usage ideas, or model provider integrations:
* Open a discussion topic in [GitHub Discussions](https://github.com/Thecimal/Free-Forever/discussions).

### 2. Reporting Bugs
If you encountered unexpected behavior or an error:
* Check that your `.env` or environment configuration is valid.
* Run `qs-orchestrator check` to test endpoint connectivity.
* Open an issue using the [Bug Report template](https://github.com/Thecimal/Free-Forever/issues/new?template=bug_report.yml).

### 3. Feature Requests
Want to suggest support for a new source adapter, strategy, or CLI command?
* Submit a request using the [Feature Request template](https://github.com/Thecimal/Free-Forever/issues/new?template=feature_request.yml).

### 4. Security Vulnerabilities
Do **not** post security bugs in public issues. Please follow our [Security Policy](SECURITY.md) to report vulnerabilities privately.
